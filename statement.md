# Project Statement

## Problem Statement
[cite_start]The challenge is to implement a robust, modular software system capable of managing a catalog of books, accepting user ratings, and performing statistical aggregation to generate analytical reports, focusing on the correct application of subject concepts like modularity and data structures[cite: 99].

## Scope of the Project
[cite_start]The project is strictly limited to a **command-line application (CLI)**[cite: 100].

* **Inclusions:** Core data management (CRUD), rating input, average calculation, and text-based reporting (top lists, detailed reports).
* **Exclusions:** A graphical user interface (GUI), persistent database storage (data resets on restart), and complex user authentication are outside the current scope.

## Target Users
* [cite_start]**End User:** Any individual who wishes to **submit ratings** for books in the system[cite: 102].
* **Administrator/Analyst:** The person responsible for **adding new books** and **viewing the analytical reports** (e.g., top-rated lists and book statistics).

## High-Level Features
1.  **Book Creation/Deletion:** Full control over the book catalog.
2.  **Rating Submission:** Simple, validated input for user ratings (1-5).
3.  [cite_start]**Analytics:** Calculation of average rating and display of ranking reports[cite: 103].
