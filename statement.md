# Project Statement

## Problem Statement
The challenge is to implement a robust, modular software system capable of managing a catalog of books, accepting user ratings, and performing statistical aggregation to generate analytical reports, focusing on the correct application of subject concepts like modularity and data structures.

## Scope of the Project
The project is strictly limited to a **command-line application (CLI)**.

* **Inclusions:** Core data management, rating input, average calculation, and text-based reporting (top lists, detailed reports).
* **Exclusions:** A graphical user interface, persistent database storage (data resets on restart), and complex user authentication are outside the current scope.

## Target Users
* **End User:** Any individual who wishes to **submit ratings** for books in the system.
* **Administrator/Analyst:** The person responsible for **adding new books** and **viewing the analytical reports** (e.g., top-rated lists and book statistics).

## High-Level Features
1.  **Book Creation/Deletion:** Full control over the book catalog.
2.  **Rating Submission:** Simple, validated input for user ratings (1-9).
3.  **Analytics:** Calculation of average rating and display of ranking reports.
